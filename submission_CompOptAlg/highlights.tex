\section*{Research Highlights}
\begin{itemize}
    \item Formulates state-robust portfolio selection over a continuous family of kernel-weighted conditional return distributions.
    \item Establishes continuity, convexity, and existence properties of the resulting semi-infinite CVaR model.
    \item Solves a finite grid-restricted approximation using adaptive constraint generation and a full-grid separation oracle.
    \item Evaluates grid resolution, bandwidth, empirical support, transaction costs, and bootstrap sensitivity.
    \item Reports competitive long-run wealth but no statistically significant Sharpe-ratio advantage over standard benchmarks.
\end{itemize}
