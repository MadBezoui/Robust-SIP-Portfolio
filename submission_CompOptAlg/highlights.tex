\section*{Research Highlights}
\begin{itemize}
    \item Proposes a continuous-state robust portfolio model, replacing rigid discrete regimes.
    \item Formulates the problem as a Semi-Infinite Program (SIP) using kernel-weighted returns.
    \item Develops an adaptive constraint generation algorithm for tractable, exact SIP solutions.
    \item Establishes a spatial dispersion diagnostic bounding the continuous optimality gap.
    \item Validates the framework via a comprehensive 31-year rolling out-of-sample backtest.
\end{itemize}
