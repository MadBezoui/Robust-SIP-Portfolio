\section*{Research Highlights}

\begin{itemize}[leftmargin=*]
    \item Formulates state-robust portfolio selection over a continuous family of kernel-weighted conditional return distributions.
    \item Solves a finite grid-restricted approximation using adaptive constraint generation, achieving a $\sim 20\times$ speedup on representative windows while retaining an average of 3.66 active states out of 441.
    \item Provides a continuous-optimality error bound and a posteriori verification, establishing that the finite grid supremum matches the continuous supremum to $10^{-4}$ precision.
    \item Reports competitive long-run wealth, though studentized bootstrap inference shows no statistically significant Sharpe-ratio advantage over standard benchmarks.
    \item Ensures full transparency with an open-source, reproducible codebase under an MIT License.
\end{itemize}
